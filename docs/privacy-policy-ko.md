# 메모리아 개인정보처리방침

시행일: 2026-07-27

메모리아는 사용자가 암기 카드를 만들고 복습할 수 있도록 돕는 학습 앱입니다. 이 문서는 앱이 어떤 정보를 수집하고, 어떻게 사용하며, 사용자가 데이터를 삭제할 수 있는 방법을 설명합니다.

## 운영자 및 문의

- 앱 이름: 메모리아
- 운영자/개발자: youwon35
- 개인정보 문의 이메일: youwon35@gmail.com
- 앱 내 문의 경로: 앱 정보 > 문의하기

## 수집 또는 저장되는 정보

- 사용자가 입력하거나 파일로 가져온 카드 앞면/뒷면, 폴더, 학습 기록, 일일 학습 목표
- Google 로그인 사용 시 계정 이메일과 사용자 식별자
- 문의하기 사용 시 답변 받을 이메일, 문의 분류, 문의 내용, 접수 상태
- 로그인 사용자의 앱 실행 기록 같은 운영 지표

## 이용 목적

- 카드 저장과 기기 간 동기화
- 학습 기록 제공과 오답 복습
- 문의 응대와 앱 데이터 삭제 처리
- 앱 안정성 확인과 품질 개선

## 제3자 처리

메모리아는 사용자의 카드 내용과 문의 내용을 판매하지 않습니다. 다만 로그인, 동기화, 데이터 저장, 문의 처리를 위해 Supabase 같은 서비스 제공업체에 정보가 저장될 수 있습니다.

## 보안

동기화와 문의 데이터는 HTTPS 통신을 통해 전송됩니다. 사용자는 Google 계정과 기기 보안을 직접 관리해야 합니다.

## 보관 및 삭제

로컬 데이터는 앱 삭제 또는 앱 데이터 삭제 시 기기에서 제거됩니다. Android 기기 백업에는 메모리아의 로컬 데이터를 포함하지 않도록 설정되어 있습니다. Google 로그인으로 만든 메모리아 계정과 동기화된 카드, 폴더, 학습 기록, 오답 기록, 일일 학습 목표, 문의 기록, 계정 연결 운영 지표, 동기화 데이터는 앱 정보의 `메모리아 계정 삭제`에서 삭제할 수 있습니다. 이 작업은 메모리아 인증 계정과 연결 데이터를 삭제하지만 Google 계정 자체는 삭제하지 않습니다. 법적 의무, 보안, 분쟁 대응을 위해 필요한 정보는 필요한 기간 동안 보관될 수 있습니다.
