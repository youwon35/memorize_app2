# MEMORIA 계정 및 데이터 삭제 안내

시행일: 2026-05-15

MEMORIA에서 Google 로그인으로 동기화한 계정과 데이터 삭제를 요청할 수 있습니다.

## 앱 안에서 요청하는 방법

1. MEMORIA를 실행합니다.
2. `앱 정보` 탭을 엽니다.
3. Google 계정으로 로그인되어 있는지 확인합니다.
4. `계정/데이터 삭제` 영역에서 `삭제 요청 보내기`를 누릅니다.
5. 접수 상태는 `앱 정보 > 문의하기 > 최근 문의`에서 확인할 수 있습니다.

## 앱을 사용할 수 없는 경우

아래 정보를 포함해 운영 이메일로 요청해 주세요.

- 제목: MEMORIA 계정 및 데이터 삭제 요청
- Google 로그인 이메일
- 삭제를 원하는 데이터 범위: 계정 전체 / 동기화 카드 / 문의 기록 등

운영 이메일: [운영 이메일 입력]

## 삭제 대상

- Google 로그인으로 동기화된 카드와 폴더
- 학습 기록
- 계정 식별 정보
- 문의 기록

법적 의무, 보안, 분쟁 대응을 위해 필요한 일부 기록은 필요한 기간 동안 보관될 수 있습니다.

> Google Play Console의 데이터 삭제 URL에는 이 문서를 공개 웹페이지로 게시한 주소를 입력하세요.
