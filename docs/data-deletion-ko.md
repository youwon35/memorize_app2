# 메모리아 계정 및 데이터 삭제 안내

시행일: 2026-05-19

메모리아에서 Google 로그인으로 동기화한 계정과 데이터를 삭제할 수 있습니다.

## 앱 안에서 삭제하는 방법

1. 메모리아를 실행합니다.
2. `앱 정보` 탭을 엽니다.
3. Google 계정으로 로그인되어 있는지 확인합니다.
4. `계정 / 데이터 삭제` 영역에서 `계정 삭제하기`를 누릅니다.
5. 삭제되는 데이터 목록을 확인한 뒤 `계속`을 누릅니다.

## 앱 안에서 삭제되는 대상

- Google 로그인으로 동기화된 카드와 폴더
- 학습 기록
- 오답 기록
- 일일 학습 목표
- 문의 기록
- 앱 실행 기록 같은 계정 연결 운영 지표
- 동기화 데이터
