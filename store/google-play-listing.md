# Google Play 등록 정보 초안

## 앱 이름

메모리아

## 짧은 설명

카드쌍을 저장하고 맞춤 암기로 복습하는 간단한 학습 앱

## 전체 설명

메모리아는 외우고 싶은 내용을 앞면과 뒷면 카드쌍으로 저장하고, 원하는 폴더 범위로 암기할 수 있는 학습 앱입니다.

주요 기능:

- 폴더별 카드 관리
- 한 장씩 카드 입력
- txt, csv, xls, xlsx, docx 파일 가져오기
- 문제 수 조정과 양방향 암기
- 오답만 다시 풀기
- 날짜별 학습 기록 확인
- 저장한 카드 수정과 삭제
- Google 로그인 기반 기기 간 동기화

단어, 문장, 개념, 시험 암기 자료를 직접 정리하고 반복해서 확인할 수 있습니다.

## 출시 노트

메모리아 1.0.10 학습·저장 안정성 업데이트

- 내보낸 CSV·엑셀 카드의 다시 가져오기 개선
- 폴더별 학습 기록과 숨김 상태 분리 및 기존 기록 유지
- 숫자·기호 정답 판정과 완료한 학습 기록 보존 개선
- 대량 카드 동기화 및 계정 전환 중 저장 안정성 개선
- 앱 정보에 지금 동기화 기능 추가
- 작은 화면에서 보관함 제목과 관리 버튼 배치 개선

## 데이터 보안 입력 초안

앱이 수집할 수 있는 데이터:

- 개인 정보: 이메일 주소, 사용자 ID
- 앱 활동: 앱 실행 기록, 학습 기록
- 앱 정보 및 성능: 문의 처리를 위한 오류 제보 내용
- 사용자 생성 콘텐츠: 사용자가 입력한 카드, 폴더, 문의 내용

사용 목적:

- 앱 기능
- 계정 관리
- 분석
- 개발자 커뮤니케이션

공유:

- 데이터를 판매하지 않음
- 로그인, 동기화, 문의 처리를 위해 Supabase 같은 서비스 제공업체가 처리할 수 있음

보안:

- 전송 중 암호화: 예
- 사용자가 데이터 삭제 요청 가능: 예, 앱 안의 계정 / 데이터 삭제와 운영 이메일 문의 지원

광고:

- 광고 없음

앱 액세스:

- 주요 기능은 로그인 없이 사용 가능
- Google 로그인은 동기화 기능용

## 필요한 이미지 자산

- 앱 아이콘: 현재 `app-icon.png` 사용 가능
- 기능 그래픽: `store/memoria-feature-graphic.png` 사용 가능
- 휴대전화 스크린샷: 최소 2장 이상 권장
- 추천 스크린샷 흐름: 저장 탭, 암기 탭, 기록 탭, 보관함, 앱 정보
